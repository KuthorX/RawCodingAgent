设置

开启后，新建的会话里 agent 的文件改动和 bash 命令直接执行，不再逐个询问。每个会话仍可以在对话页顶部单独切换，已有的会话不受影响。

新会话默认模型

仅影响之后新建的会话；已有会话可在对话页顶部单独设置。

厂商连接

密钥保存在本机。已配置时留空即可保留；会话只保存模型选择。

通知需要浏览器授权；会话右键菜单可以覆盖全局通知设置。

达到阈值后，agent 会先压缩当前会话上下文；也可以输入 /compact 手动执行。
